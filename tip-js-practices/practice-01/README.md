## ЗАДАНИЕ 2

1) "8" + 2
Ожидание: "82"
Фактическое значение: "82"
Тип результата: string
Объяснение: оператор «+» выполняет конкатенацию.
Число 2 преобразуется в строку.

2) "8" - 2
Ожидание: 6
Фактическое значение: 6
Тип результата: number
Объяснение: оператор «-» - только для чисел, поэтому строка "8"
преобразуется в число 8, затем выполняется вычитание.

3) Number("8") + 2
Ожидание: 10
Фактическое значение: 10
Тип результата: number
Объяснение: Number("8") явно преобразует строку в число 8.

4) "12" > "3"
Ожидание: false
Фактическое значение: false
Тип результата: boolean
Объяснение: обе стороны — строки, поэтому сравнение идёт посимвольно.
"1" < "3", значит "12" не больше "3".

5) 12 === "12"
Ожидание: false
Фактическое значение: false
Тип результата: boolean
Объяснение: Число 12 и строка "12" - разные типы.

6) Number("")
Ожидание: 0
Фактическое значение: 0
Тип результата: number
Объяснение: пустая строка при преобразовании в число даёт 0.

7) Number("text")
Ожидание: NaN
Фактическое значение: NaN
Тип результата: number
Объяснение: нечисловую строку нельзя преобразовать в число,
поэтому получаем NaN. Сам NaN имеет тип number.

8) Boolean("false")
Ожидание: true
Фактическое значение: true
Тип результата: boolean
Объяснение: «false» - непустая строка, значит true.

9) typeof null
Ожидание: "object"
Фактическое значение: "object"
Тип результата: string
Объяснение: исключение

10) typeof NaN
Ожидание: "number"
Фактическое значение: "number"
Тип результата: string

## ЗАДАНИЕ 5

Исходный вывод:
Выполнено: 32
Осталось: -24
Контрольная сумма: 6

В точке останова на строке с инициализацией completedTotal:
additionalText: "2"      - строка
completedText: "3"       - строка
completedTotal: (uninitialized)
controlSum: (uninitialized)
plannedText: "8"
remaining Tasks: (uninitialized)

На следующем шаге:

additionalText: "2"
completedText: "3"
completedTotal: "32"      - строка
controlSum: (uninitialized)
plannedText: "8"
remainingTasks: (uninitialized)

Точка останова в цикле:

    Первая итерация:
    taskNumber: 1
    controlSum: 0

    Вторая итерация:
    taskNumber: 2
    controlSum: 1

    Третья итерация:
    taskNumber: 3
    controlSum: 3

    Прекращение цикла:
    taskNumber: 4
    controlSum: 6

После исправления:
Выполнено: 5
Осталось: 3
Контрольная сумма: 10


Ошибки:

- Обработка количества задач

    Что наблюдалось: Выполнено: 32  Осталось: -24

    Причина: completedText и additionalText - строки, поэтому выполнялась конкатенация вместо сложения.

    Исправление: задать сразу числа без «"»

    Результат после исправления: Выполнено: 5, Осталось: 3

- Граница цикла

    Что наблюдалось: Контрольная сумма: 6

    Причина: при достижении taskNumber = 4 цикл прерывается, т.к. больше не соблюдается условие taskNumber < 4

    Исправление: заменить < 4 на <= 4, чтобы цикл включал число 4

    Результат после исправления: Контрольная сумма: 10
